# CryptoJournal Pro – ساخت APK اندروید با GitHub

این پروژه یک پروژه Capacitor است که فایل `www/index.html` را به اپ اندروید تبدیل می‌کند.
ساخت APK به‌صورت خودکار توسط GitHub Actions انجام می‌شود؛ نیازی به نصب Android Studio نیست.

## مراحل

1. در GitHub یک Repository جدید بسازید (مثلاً `cryptojournal-pro`).
2. محتوای این پوشه (بعد از Extract کردن زیپ) را در ریشه Repository آپلود کنید.
   - مهم: پوشه مخفی `.github` هم باید آپلود شود.
   - اگر از وب GitHub استفاده می‌کنید، بهتر است با Git یا GitHub Desktop پوش کنید تا پوشه‌های مخفی حذف نشوند.
3. به تب **Actions** بروید. ساخت به‌صورت خودکار شروع می‌شود (یا روی **Build Android APK ← Run workflow** بزنید).
4. بعد از ۵ تا ۱۰ دقیقه، داخل همان Run در بخش **Artifacts** فایل `CryptoJournal-Pro-APK` را دانلود کنید.
5. فایل zip را باز کنید و `app-debug.apk` را روی گوشی نصب کنید (اجازه نصب از منبع ناشناس لازم است).

## تغییر در برنامه

هر تغییری در `www/index.html` بدهید و Commit کنید، APK جدید ساخته می‌شود.

## نکته‌ها

- داده‌ها داخل حافظه محلی خود اپ ذخیره می‌شوند؛ با حذف اپ پاک می‌شوند. از «ساخت CSV» در تنظیمات برای بکاپ استفاده کنید.
- فونت وزیرمتن از اینترنت لود می‌شود؛ بدون اینترنت از فونت سیستم استفاده می‌شود.
- این APK از نوع debug است و برای نصب شخصی کافی است. برای انتشار در مارکت‌ها باید نسخه release با امضا ساخته شود.
